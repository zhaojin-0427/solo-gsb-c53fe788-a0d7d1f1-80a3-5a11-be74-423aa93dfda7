# 数控铣削快移碰料检查台

上传 G-code，按模态逐行回放加工过程：切削段（G1/G2/G3）逐段从毛坯中扣除
刀具扫过的材料，快移段（G0）检查全程是否触及当前余料。首次碰料时显示
**行号、碰料位置和当时的余料深度图**；无碰料则显示安全。

技术栈：Python / FastAPI + Shapely（几何运算）+ 原生 JavaScript（无任何前端构建）。

## 快速开始（Docker Compose 一键启动）

```bash
docker compose up --build
```

然后浏览器访问 **http://localhost:8000** ，即为检查页面：

1. 输入毛坯宽/长/厚（mm）、平底刀直径（mm）、安全高度（mm，正数）；
2. 粘贴 G-code，或选择文件上传，或从下拉框载入示例；
3. 点击「开始检查」，结果页显示：
   - **安全**（绿色）：全部快移均未触及余料，并显示最终余料深度图；
   - **首次碰料**（红色）：行号、该行指令、碰料位置 (X, Y, Z)、该处余料
     顶面深度，以及**碰料发生时刻**的余料深度图与刀具轨迹；
   - **程序错误**（黄色）：非法圆弧 / 不支持的指令 / 切削穿底，附行号。

停止服务：`docker compose down`。

## 本地运行（不用 Docker）

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000 。运行测试：`python3 tests/test_core.py`。

## 模型约定

- 毛坯为长方体：左下角 (0, 0)，范围 [0, 宽] × [0, 长]，**顶面 Z=0**，
  底面 Z=-厚；起点为 **(0, 0, 安全高度)**。
- 默认模态 **G17 / G21 / G90**，初始运动模态 G0。
- 刀具为平底立铣刀，快移时视为刀尖向上的圆柱体。

## 支持的指令

| 指令 | 说明 |
| --- | --- |
| `G0` | 快移（检查对象） |
| `G1` | 直线切削（含坡铣，Z 可变化） |
| `G2` / `G3` | 顺/逆时针圆弧切削，`I`/`J` 圆心偏移**始终相对于段起点**；不给 X/Y 终点时为**整圆**；`Z` 沿圆弧转角**线性变化**（螺旋插补） |
| `G17` | XY 平面（默认） |
| `G20` / `G21` | 英寸 / 毫米（毛坯与刀具输入始终为毫米） |
| `G90` / `G91` | 绝对 / 增量编程（`I`/`J` 不受 G91 影响，始终相对段起点） |

- `F` / `S` / `N` 字被接受但忽略；`(...)` 与 `;` 注释、空行、`%` 行被跳过。
- 运动模态有记忆：无 G 字的轴移动行沿用上一运动模态；行号为**原文件行号**。

## 碰料判定规则

- 切削段把刀具扫过的区域按**该段最低刀尖 Z** 从余料中扣除；坡铣与螺旋
  插补被细分为小段，**各处切深分别保留**（余料为分区深度模型）。
- 快移段全程（含 Z 变化的斜线/垂直移动）逐段检查：
  - 刀尖压入材料内部（材料顶面高于刀尖）→ 碰料；
  - 与**未加工表面**（顶面 Z=0）相切也算碰料（**切线接触算碰料**）；
  - 快移**可以利用此前已切出的空腔**：贴着自己切出的腔壁/腔底
    （零间隙）不算碰料，但不得压到腔底以下。
- 首次碰料即停止，报告行号、刀尖位置与该处余料顶面深度。

## 错误处理（标行号并停止）

- **非法圆弧**：终点不在圆上（半径超差）、圆心与起点重合、缺少 `I`/`J`
  （不支持 `R` 编程）；
- **不支持的指令**：除上表外的 G 代码（如 `G28`、`G4`）、`M`/`T` 等字；
- **切削穿底**：切削段刀尖 Z 低于毛坯底面（Z < -厚）；
- 无法解析的行内容。

## API

`POST /api/check`，JSON 请求体：

```json
{
  "gcode": "G21 G90 G17\nG0 X10 Y10\n...",
  "stock_width": 100, "stock_length": 80, "stock_thickness": 20,
  "tool_diameter": 6, "safe_height": 5
}
```

响应：`status` 为 `safe` / `collision` / `error`；碰料时含 `line`、
`line_text`、`position`、`material_top`；另含 `depth_map`（余料深度栅格）
与 `path`（轨迹，供前端绘图）。
